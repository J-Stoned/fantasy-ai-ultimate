# Player Domain

This domain handles all player-related operations including data collection, analysis, and migrations.

## Structure

- **collectors/**: Scripts for collecting player data from various sources
- **analyzers/**: Scripts for analyzing player performance and trends
- **migrations/**: Scripts for migrating and updating player data

## Key Scripts

### Collectors
- Player data collection from various sports APIs
- Historical player data collection
- Missing player identification and collection

### Analyzers
- Player performance analysis
- Position analysis
- Player comparison tools

### Migrations
- Player data standardization
- Position mapping
- Player ID consolidation
