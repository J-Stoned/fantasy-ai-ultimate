# Machine Learning Domain

This domain handles all ML-related operations including training, prediction, and data enrichment.

## Structure

- **training/**: Model training scripts and pipelines
- **models/**: ML model definitions and implementations
- **prediction/**: Prediction services and APIs
- **enrichment/**: Data enrichment and feature engineering

## Key Components

### Training
- Sport-specific model trainers
- Ensemble model training
- Cross-validation and backtesting

### Models
- Player performance predictors
- DFS lineup optimizers
- Ownership projection models
- Contest selection AI

### Prediction
- Real-time prediction services
- Batch prediction pipelines
- Model serving infrastructure

### Enrichment
- Feature engineering
- Data preprocessing
- External data integration (weather, injuries, etc.)
