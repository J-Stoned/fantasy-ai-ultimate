# Stats Domain

This domain handles all statistics-related operations including collection, calculation, analysis, and validation.

## Structure

- **collectors/**: Scripts for collecting stats from various sports
- **calculators/**: Fantasy point calculators and scoring engines
- **analyzers/**: Statistical analysis tools
- **validators/**: Data validation and quality checks

## Key Scripts

### Collectors
- Sport-specific stats collectors (NFL, NBA, MLB, NHL, NCAA)
- Real-time stats collection
- Historical stats collection

### Calculators
- DFS scoring calculators
- Traditional fantasy scoring
- Custom scoring systems

### Analyzers
- Performance trend analysis
- Statistical comparisons
- Advanced metrics calculation

### Validators
- Data completeness checks
- Stats accuracy validation
- Duplicate detection
